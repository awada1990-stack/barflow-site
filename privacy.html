Privacy Policy

Last updated: 30 October 2026

BarFlow Social Manager ("the app") is a desktop application that runs locally on the owner's computer.

Data the app accesses

When the owner signs in with Google, the app requests access to the owner's own YouTube channel in order to upload videos, post comments, and read analytics (scopes: youtube.upload, youtube.force-ssl, yt-analytics.readonly).

How data is stored

Access tokens and all content are stored only on the owner's own computer, with tokens encrypted by the operating system. The app has no server, does not collect telemetry, and does not send any data to the developer or to any third party.

Sharing

We do not sell, share or transfer Google user data to anyone. Data is sent only to the platform's own API (for example YouTube) to perform the actions the owner requests.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions or by disconnecting the account in the app.
